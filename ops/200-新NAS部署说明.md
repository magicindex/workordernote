> **0.9.0 那次的教训（务必照做）**：升级顺序必须是
> ① `scp` 新镜像 tar.gz 上去 → ② `sudo docker load -i images/workordernote-0.9.0-amd64.tar.gz` →
> ③ 改 `docker-compose.yml` 里的标签 → ④ `sudo docker compose up -d --force-recreate`。
> `docker compose up` 是**先删旧容器再建新的**：镜像没 load 就 up，旧容器已经被删掉、新容器又建不起来，
> 应用会直接停着（本轮真出现，约 1 分钟后恢复）。
