农历建卡更顺手，卡片日期更醒目，底部文字可自定义。

### 新增

- **农历建卡真正按农历计算**：新建或修改卡片时选「农历」，日期弹层会直接落在农历页签；选中的农历月日会保存为循环锚点，不再出现「选了农历却按当天公历计算」。
- **卡片日期胶囊**：只给创建时选中历法的「月日 + 每年」加高饱和底色（公历蓝、农历琥珀），年份和另一种日历不加底色；「每年」跟随创建时的历法。
- **卡片底部文字可自定义**：编辑事项时填写「卡片底部文字」；留空自动显示「与你共度第 N 次…」。

### 调整

- **表单排布**：日期、历法、重复收进同一行、三列等宽；手机窄屏日期改用 `2011/10/13` 短格式，不再截断。
- **农历写法**：年后加空格（丁未年 正月初九）；闰月写「闰六月」、十二月写「腊月」、一月写「正月」，二十一写「廿一」。
- **次数文案统一**：卡片底部统一写「与你共度第 N 次生日 / 第 N 次情人节 / 第 N 周年」。

### 安装（Docker Compose）

```bash
mkdir -p workordernote && cd workordernote
curl -fsSLO https://raw.githubusercontent.com/magicindex/workordernote/main/docker-compose.yml
docker compose up -d
```

打开 `http://<主机>:8906`，首次启动后注册管理员账号。也可以克隆仓库后自行构建，或从 Release 下载镜像包导入。
