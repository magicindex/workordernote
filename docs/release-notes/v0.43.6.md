# 工作序记 v0.43.6（2026-10-27）

课程表按周留档，手机直接看今天。

### 新增

- **每周独立快照**：课程表按自然周保存，可切「上一周 / 下一周」；过去周只读，编辑本周不影响历史。
- **批量共享**：共享弹窗可勾选多张自有课程表，填一个账号、选「只读 / 读写」，一次提交；名单按表聚合，可单独改权限或移除。
- **课程备注进随手记事本**：课程备注保存为「课程备注：课程名」，同一门课再次保存更新同一条，删课保留备注。
- **记事本课程备注筛选**：随手记事本工具栏新增「课程备注」按钮，课程备注行用课程卡片样式展示。

### 调整

- **手机课程表默认看今天**：手机端显示一～日日期条，默认选中今天，只展开当天课程；桌面仍显示整周。
