先备份，再折腾：整库与上传文件，本机或 WebDAV 每天自动留一份。

### 新增

- **数据备份**：系统配置 →「数据备份」可开启每日定时备份，把整个数据库（所有账号、清单、提醒、完成记录、课程表、配置）与上传文件打成 `workordernote-backup-YYYYMMDD-HHMMSS.tar.gz`。本机目录与 WebDAV 可同时开启，各自保留最近 N 份。
- **立即备份**：面板上可随手跑一次，显示上次时间、结果与文件路径。WebDAV 支持 Basic 认证、子目录自动创建与旧文件清理；密码用密码框输入，且不参与双机同步。
- **备份范围**：整库 + `uploads/`（仪式感卡片背景图等）；不含运行日志与容器环境变量。

### 调整

- **课程表少一个开关**：「编辑」与「空节次」合并成一个「编辑课程表」按钮，进编辑态自动铺出空节次，退出即收起。
- **课程表更清爽**：早课 / 上午 / 下午 / 晚课之间不再画横线，段名即分隔；「编辑课程表」按钮与标签条等高。
- **首页看板**：两栏条目与标题条之间留出间距；待办条目改用与标题一致的浅蓝边框。
- **侧栏设置入口**：默认不选中，鼠标悬停或键盘聚焦才显示选中底色。

### 安装

```bash
git clone https://github.com/magicindex/workordernote.git
cd workordernote
docker compose up -d --build
```

默认访问 `http://<主机>:8906`，首次打开按提示注册管理员。

### 容器镜像

```bash
docker pull ghcr.io/magicindex/workordernote:0.41.0
docker run -d -p 8906:8906 -v workordernote-data:/app/data ghcr.io/magicindex/workordernote:0.41.0
```

也可以下载 `workordernote-0.41.0-image.tar.gz` 后 `docker load -i` 导入。
