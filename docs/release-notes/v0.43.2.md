### 修复

- **仪式感农历年份**：卡片第二行的农历年份由「二〇二六年」改为干支「丙午年」，例如 2026-10-25 显示为「丙午年九月十六」；月日写法与公历/农历换算不变。

### 安装（Docker Compose）

```bash
mkdir -p workordernote && cd workordernote
curl -fsSLO https://raw.githubusercontent.com/magicindex/workordernote/main/docker-compose.yml
docker compose up -d
```

打开 `http://<主机>:8906`，首次启动后注册管理员账号。也可以克隆仓库后自行构建，或从 Release 下载镜像包导入。
