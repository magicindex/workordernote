生日不再算错逾期，备份证书可跳过校验。

### 修复

- **年度循环提醒不再按首次年份算逾期**：生日、纪念日等「每年」条目按当前年份/当前农历年计算这一轮日期；完成确认后跳过已经过去的周期，直接落到当前或下一轮。
- **WebDAV 自签名证书**：数据备份新增「跳过 HTTPS 证书校验」，自签名证书或用 IP 访问而证书缺少 IP SAN 时可正常上传；失败信息会提示改用证书主机名或打开开关。

### 调整

- **倒计时历法**：编辑表单的「历法」改为「倒计时历法」。
- **日期与周期拆分**：卡片上只有月日套历法底色，「每年」独立显示；列表循环徽标写「农历9月17日 每年」/「公历2026年9月17日 每年」。

### 安装（Docker Compose）

```bash
mkdir -p workordernote && cd workordernote
curl -fsSLO https://raw.githubusercontent.com/magicindex/workordernote/main/docker-compose.yml
docker compose up -d
```

打开 `http://<主机>:8906`，首次启动后注册管理员账号。也可以克隆仓库后自行构建，或从 Release 下载镜像包导入。
