备份能恢复，课程表手机也能进。

### 新增

- **数据恢复**：系统配置 →「数据备份」新增恢复区，可列出本机 `workordernote-backup-*.tar.gz`，也可上传别处保存的备份。确认后覆盖整库与上传文件（账号、清单、提醒、完成记录、课程表、配置与图片，不含日志）。
- **恢复保护**：恢复前自动生成 `...-before-restore.tar.gz` 安全备份；数据库用 SQLite 在线备份 API 整库复制，恢复后自动补表结构；数据库写入失败时回滚上传文件。收包会拒绝路径穿越、软硬链接、异常大小与损坏库。
- **手机清单弹层课程表**：手机底部「清单」弹层顶部新增课程表入口，点击直达并收起弹层；课程表页打开弹层时打勾。

### 调整

- **仪式感双历日期**：倒计时卡片日期分两行，第一行公历，第二行农历中文写法，去掉单独的「农历」标签；换算失败只隐藏第二行。
- **信用卡「更多」**：由悬停展开改为点击展开，点页面其他位置收起。

### 安装（Docker Compose）

```bash
mkdir -p workordernote && cd workordernote
curl -fsSLO https://raw.githubusercontent.com/magicindex/workordernote/main/docker-compose.yml
docker compose up -d
```

打开 `http://<主机>:8906`，首次启动后注册管理员账号。也可以克隆仓库后自行构建，或从 Release 下载镜像包导入。
