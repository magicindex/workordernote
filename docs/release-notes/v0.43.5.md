课程表可共享，手机入口更顺手。

### 新增

- **课程表共享**：表主按登录用户名共享课程表，权限分「只读」「读写」；只读只能查看课程详情，读写可增删改课程，但不能改表设置、删表或再共享。
- **悬浮新建按频道分流**：提醒@他页新建提醒、信用卡页新建卡片、仪式感页新建事项，其余频道新建待办。

### 调整

- **手机清单入口**：课程表、提醒@他、信用卡、记事本、仪式感统一排在自建清单前；课程表栏目默认开启。
- **底部标签**：手机底部「方式」改为「提醒」，直达提醒@他页面；通知方式仍在侧栏抽屉。
- **内置栏目开关**：信用卡与仪式感关闭后，侧栏、清单、条目、日历与统计同步隐藏，重新打开立即恢复。

### 修复

- **手机提醒@他**：别人提醒我的事项确认完成后立即从「待处理」消失，与电脑端一致。
- **栏目开关缓存**：修改信用卡/仪式感开关后立即生效，不再等待 2 秒缓存。

### 安装（Docker Compose）

```bash
mkdir -p workordernote && cd workordernote
curl -fsSLO https://raw.githubusercontent.com/magicindex/workordernote/main/docker-compose.yml
docker compose up -d
```

打开 `http://<主机>:8906`，首次启动后注册管理员账号。也可以克隆仓库后自行构建，或从 Release 下载镜像包导入。
