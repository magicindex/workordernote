# 工作序记 v0.43.7

黑卡水晶新卡面，课程表按周自动沿用。

## 新增

- **垃圾箱**：智能清单最后新增「垃圾箱」，所有已删除提醒集中在这里，可恢复回原清单；「全部」与「已完成」不再包含已删除记录。
- **仪式感图标库**：卡片图标放大到 112px，点击即可更换；内置节日、纪念、日常三组图标，并可按标题自动匹配春节、中秋、考试、生日等图标。
- **课程表跨周沿用**：新一周自动沿用上一周课程；本周修改后，下周沿用最新一次修改。

## 调整

- **课程表取消周切换**：移除上一周/下一周入口，只显示当前周，避免历史周与未来周产生重复条目。
- **课程备注图标**：随手记事本里的课程备注行改用课程表图标。
- **手机课程表**：选中日期改为实心品牌蓝，其余日期灰暗；当天内容更醒目。

## 修复

- **跨设备重复课程**：跨周复制使用确定性 `sync_uid`，两台设备各自复制也不会合并成重复条目；旧版空白的未来周记录会自动清理。
